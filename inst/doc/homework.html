The Rayleigh density [162, Ch. 18] is \(f(x) = \frac{x}{\sigma^2} e^{-x^2 / (2\sigma^2)}, \quad x \ge 0, \sigma > 0.\)Develop an algorithm to generate random samples from a Rayleigh(σ) distribution. Answer 3.4

逆变换算法

Rayleigh(\(\sigma\)) distribution 的分布函数能表示成\[ F(x) = \int_{0}^{x} \frac{t}{\sigma^2} e^{-t^{2}/ (2 \sigma^{2})} dt=1-e^{-x^2/(2\sigma^2)} \]

利用逆变换采样法，令U=F(X)，则U是均匀分布(0,1)的随机变量。设\(u=F(x)\)可以得到\(x=\sqrt{-2\sigma^2ln(1-u)}\)

则要生成一个服从参数为\(\sigma\)的Rayleigh(\(\sigma\)) distribution的随机样本x，我们只需要：

1.从Uniform(0,1) 分布中生成一个随机数u

2.利用以下公式计算x：\(x=\sigma \sqrt{-2ln(u)}\)

Question

Write a function to generate a random sample of size n from the Beta(a, b) distribution by the acceptance-rejection method. Generate a random sample of size 1000 from the Beta(3,2) distribution. Graph the histogram of the sample with the theoretical Beta(3,2) density superimposed.

Answer 3.7

由于Beta分布的支撑集是[0,1],我们令提议分布为标准均匀分布，其密度函数为\(g(x)=1\),则我们寻找的常数M为Beta(3,2)分布的概率密度函数的最大值。

接受拒绝函数

对应接受拒绝函数为以下所示

beta_rejection_sampler <- function(n, a, b) {
  # 计算常数 M，即目标分布 f(x) 的最大值。
  # 对于 a>1, b>1 的 Beta 分布，其众数（峰值点）在 (a-1)/(a+b-2)
  # 如果 a<=1 或 b<=1，峰值可能在 0 或 1，或者函数是单调的。
  # 为了通用性，我们可以使用 optimize 函数寻找 f(x) 在 [0, 1] 上的最大值。
  # dbeta 是 R 中 Beta 分布的密度函数。
  m_optim <- optimize(f = function(x) dbeta(x, a, b), 
                      interval = c(0, 1), 
                      maximum = TRUE)
  M <- m_optim$objective # 提取找到的最大值
  
  # 初始化一个用于存放结果的空向量
  samples <- numeric(n)
  count <- 0 # 记录已接受的样本数
  
  while (count < n) {
    # 步骤 1: 从提议分布 g(x) = U(0, 1) 中抽取一个候选样本
    candidate <- runif(1)
    
    # 步骤 2: 从 U(0, 1) 中抽取一个随机数 u，用于决定是否接受
    u <- runif(1)
    
    # 步骤 3: 计算接受概率 f(candidate) / (M * g(candidate))
    # 因为 g(x) = 1, 所以这简化为 f(candidate) / M
    acceptance_prob <- dbeta(candidate, a, b) / M
    
    # 步骤 4: 如果 u 小于等于接受概率，则接受该候选样本
    if (u <= acceptance_prob) {
      count <- count + 1
      samples[count] <- candidate
    }
  }
  
  return(samples)
}

Write a function to compute a Monte Carlo estimate of the Beta(3, 3) cdf, and use the function to estimate F(x) for x = 0.1, 0.2, . . . , 0.9. Compare the estimates with the values returned by the pbeta function in R.

Answer 6.4

下面用蒙特卡洛方法近似 Beta(3,3) 分布的累积分布函数\(F(X)=Pr(X\leq x)\)。

令\(X_1,X_2,\dots,X_n \stackrel{iid}{\sim}Beta(3,3)\),对于任意给定的x,估计量\(\hat{F_n}(x)=\frac{1}{n}\sum_{i=1}^{n} I(X_i \leq x)\),该估计为无偏的，方差为\(\mathrm{Var}(\hat{F}_{n}(x))\approx\frac{F(x)(1-F(x))}{n}\),abs_err表示估计值与pbeta函数给出的值的绝对误差。

## Monte Carlo CDF for Beta(3,3) and comparison to pbeta
mc_beta_cdf <- function(x, n = 1e5, seed = NULL) {
  if (!is.null(seed)) set.seed(seed)
  z <- rbeta(n, shape1 = 3, shape2 = 3)        # 一次生成，用于所有 x
  est <- se <- lcl <- ucl <- numeric(length(x))
  for (i in seq_along(x)) {
    phat <- mean(z <= x[i])
    est[i] <- phat
    se[i]  <- sqrt(phat * (1 - phat) / n)      # 估计的标准误
    lcl[i] <- pmax(0, phat - 1.96 * se[i])     # 约95%置信区间
    ucl[i] <- pmin(1, phat + 1.96 * se[i])
  }
  data.frame(x = x, mc_est = est, se = se, lcl = lcl, ucl = ucl)
}

Question

Obtain the stratified importance sampling estimate in Example 6.14 and compare it with the result of Example 6.11.

Answer 6.15

将区间 \((0,1)\) 等分为 \(K=5\) 个分层： \[ I_k \;=\;\Big(\tfrac{k-1}{5},\,\tfrac{k}{5}\Big),\qquad k=1,2,3,4,5, \] 并写 \[ \theta \;=\;\sum_{k=1}^5 \theta_k,\qquad \theta_k \;=\;\int_{I_k} g(x)\,dx. \]

在第 \(k\) 层 \(I_k=(a_k,b_k)\)（其中 \(a_k=\frac{k-1}{5}\)、\(b_k=\frac{k}{5}\)）内， 采用将 \(f_3\) 截断到该层并重新归一化后的密度 \[ f_k(x)\;=\;\frac{e^{-x}}{\int_{a_k}^{b_k} e^{-t}\,dt} \;=\;\frac{e^{-x}}{e^{-a_k}-e^{-b_k}}, \qquad x\in (a_k,b_k). \] 对该截断指数分布，可用逆变换采样：令 \(U\sim\mathrm{Unif}(0,1)\)，则 \[ X\;=\;-\log\!\Big(e^{-a_k}-U\,\big(e^{-a_k}-e^{-b_k}\big)\Big)\;\sim\; f_k. \]

在第 \(k\) 层独立抽取 \(n_k\) 个样本 \(X_{k,1},\dots,X_{k,n_k}\sim f_k\)，则 \[ \widehat{\theta}_k \;=\;\frac{1}{n_k}\sum_{i=1}^{n_k}\frac{g(X_{k,i})}{f_k(X_{k,i})} \quad\text{是 }\theta_k\text{ 的无偏估计，} \] 从而 \[ \widehat{\theta}_{\mathrm{SIS}} \;=\;\sum_{k=1}^5 \widehat{\theta}_k \quad\text{是 }\theta\text{ 的无偏估计。} \] 为实现方便，注意到 \[ \frac{g(X)}{f_k(X)} \;=\; g(X)\,\frac{e^{-a_k}-e^{-b_k}}{e^{-X}} \;=\; g(X)\,\big(e^{-a_k}-e^{-b_k}\big)\,e^{X}, \] 可直接按此式计算权重。

设层内随机变量 \[ Y_{k,i}\;=\;\frac{g(X_{k,i})}{f_k(X_{k,i})},\qquad \bar{Y}_k \;=\;\frac{1}{n_k}\sum_{i=1}^{n_k}Y_{k,i},\qquad s_k^2 \;=\;\frac{1}{n_k-1}\sum_{i=1}^{n_k}\big(Y_{k,i}-\bar{Y}_k\big)^2. \] 由于各层独立， \[ \mathrm{Var}\!\big(\widehat{\theta}_{\mathrm{SIS}}\big) \;=\;\sum_{k=1}^5 \mathrm{Var}(\bar{Y}_k) \;\approx\;\sum_{k=1}^5 \frac{s_k^2}{n_k}, \qquad \mathrm{SE}\!\big(\widehat{\theta}_{\mathrm{SIS}}\big) \;=\;\sqrt{\sum_{k=1}^5 \frac{s_k^2}{n_k}}. \] 常用的样本量分配为等额分配 \(n_k=m/5\)；若需进一步降低方差，可采用 Neyman 分配 \[ n_k \;\propto\; \sigma_k \;\approx\; s_k, \] 但需预估各层标准差。

set.seed(123)  # 便于复现
m <- 10000     # 总模拟次数
K <- 5         # 分层数
nk <- rep(m / K, K)

# 被积函数 g(x) = e^{-x}/(1+x^2) 在 (0,1)
g <- function(x) {
  exp(-x) / (1 + x^2) * (x > 0 & x < 1)
}

##### 一、对比基线：Example 6.11 中用 f3 的重要性抽样 #####
# f3(x) = e^{-x}/(1 - e^{-1}), 0<x<1
# 用逆变换从 f3 抽样：U~Unif(0,1), X = -log(1 - U*(1 - e^{-1}))
u <- runif(m)
x_f3 <- -log(1 - u * (1 - exp(-1)))
w_f3 <- g(x_f3) / (exp(-x_f3) / (1 - exp(-1)))  # 权重 g/f3
theta_hat_f3 <- mean(w_f3)
sd_f3 <- sd(w_f3)
se_f3 <- sd_f3 / sqrt(m)

##### 二、分层重要性抽样（SIS） #####
# 每层 I_k = ((k-1)/K, k/K)，在该层内用 f_k(x) ∝ e^{-x} 且截断到 I_k
# 抽样：若 U~Unif(0,1), X = -log( exp(-a) - U*(exp(-a)-exp(-b)) )
theta_hat_by_stratum <- numeric(K)
var_by_stratum <- numeric(K)

for (k in 1:K) {
  a <- (k - 1) / K
  b <- k / K
  u <- runif(nk[k])
  xk <- -log( exp(-a) - u * (exp(-a) - exp(-b)) )
  # 层内密度 f_k(x) = e^{-x} / (exp(-a) - exp(-b))
  wk <- g(xk) / (exp(-xk) / (exp(-a) - exp(-b)))  # = g(xk)*(exp(-a)-exp(-b))*exp(xk)

  theta_hat_by_stratum[k] <- mean(wk)         # 估计该层积分
  var_by_stratum[k] <- var(wk) / nk[k]        # 该层样本均值的方差估计
}

theta_hat_sis <- sum(theta_hat_by_stratum)       # 总积分估计
se_sis <- sqrt(sum(var_by_stratum))              # 总标准误

##### 三、结果汇总 #####
out <- rbind(
  estimate = c(theta_hat_f3, theta_hat_sis),
  MC_sd    = c(sd_f3, sqrt(sum(var_by_stratum) * m / m)),  # 显示量级供参考
  MC_se    = c(se_f3, se_sis)
)
colnames(out) <- c("IS with f3 (Example 6.11)", "Stratified IS (Example 6.14)")
print(round(out, 6))

simulate_type1_once <- function(rdist, mu0, n, B = 10000, alpha = 0.05) {
  rejections <- logical(B)
  for (b in seq_len(B)) {
    x <- rdist(n)
    p <- t.test(x, mu = mu0)$p.value  # two-sided by default
    rejections[b] <- (p < alpha)
  }
  rate <- mean(rejections)

## --- 两样本 Cramér–von Mises 统计量 W^2（式 10.14）---
cvm_W2 <- function(x, y) {
  x <- sort(x); y <- sort(y)
  n <- length(x); m <- length(y)

  rk <- rank(c(x, y), ties.method = "average")  # 合并秩（并列取平均）
  r.x <- rk[1:n]
  r.y <- rk[(n + 1):(n + m)]

  U  <- n * sum((r.x - seq_len(n))^2) +
        m * sum((r.y - seq_len(m))^2)

  W2 <- U / (n * m * (n + m)) - (4 * m * n - 1) / (6 * (m + n))
  return(W2)
}

## --- 置换检验封装 ---
cvm_perm_test <- function(x, y, R = 9999, seed = 42L) {
  if (!is.null(seed)) set.seed(seed)
  z <- c(x, y); N <- length(z); n <- length(x)

  W0 <- cvm_W2(x, y)
  reps <- numeric(R)
  for (i in seq_len(R)) {
    k  <- sample.int(N, size = n, replace = FALSE)
    x1 <- sort(z[k])
    y1 <- sort(z[-k])
    reps[i] <- cvm_W2(x1, y1)
  }
  pval <- mean(c(W0, reps) >= W0)  # 大者显著
  list(statistic = W0, p.value = pval, reps = reps)
}

Question

Prove that the stationary distribution of the M-H sampler with proposal distribution g(r|s) is the target distribution f (x) in the CONTINUOUS case.

Answer

\[ K(\mathrm{d}r\mid s) = g(r\mid s)\,\alpha(s,r)\,\mathrm{d}r + \Big[1-\int g(u\mid s)\,\alpha(s,u)\,\mathrm{d}u\Big]\delta_s(\mathrm{d}r). \tag{1} \]

由接受率定义， \[ \begin{aligned} f(s)g(r\mid s)\alpha(s,r) &= f(s)g(r\mid s)\min\!\left\{1,\frac{f(r)g(s\mid r)}{f(s)g(r\mid s)}\right\}\\ &= \min\!\big\{f(s)g(r\mid s),\,f(r)g(s\mid r)\big\}. \end{aligned} \] 同理 \[ f(r)g(s\mid r)\alpha(r,s) = \min\!\big\{f(r)g(s\mid r),\,f(s)g(r\mid s)\big\}. \] 因而 \[ f(s)\,g(r\mid s)\alpha(s,r)\,\mathrm{d}r = f(r)\,g(s\mid r)\alpha(r,s)\,\mathrm{d}s. \tag{2} \]

把（2）对 \(s\)（或 \(r\)）积分并与（1）配对，可得 \[ \int f(s)K(\mathrm{d}r\mid s)\,\mathrm{d}s = \int\!\!\left[\int f(r)g(s\mid r)\alpha(r,s)\,\mathrm{d}s\right]\mathrm{d}r + \int f(r)\!\left[1-\int g(s\mid r)\alpha(r,s)\,\mathrm{d}s\right]\!\mathrm{d}r = f(r)\,\mathrm{d}r. \tag{3} \]

对任意可测集 \(A\)，由（3）立刻得到 \[ \int f(s)K(A\mid s)\,\mathrm{d}s=\int_A f(r)\,\mathrm{d}r, \] 即 \(f\) 是 \(K\) 的不变（平稳）分布。若再假设链不可约、非周期等，则 \(f\) 也是唯一平稳分布，MH 样本分布收敛到 \(f\)。

      x[t] <- y
      accept <- accept + 1
    } else {
      x[t] <- x[t - 1]
    }
  }
  
  list(chain = x,
       accept_rate = accept / (N - 1))
}

## Gibbs sampler for the joint density in Exercise 11.10
## f(x,y) ∝ C(n,x) y^{x+a-1} (1-y)^{n-x+b-1}

gibbs_betabinom <- function(N, a, b, n, x0 = 0, y0 = 0.5) {
  # N: total iterations
  # a, b, n: parameters in the joint density
  # x0, y0: initial values
  
  x <- numeric(N)
  y <- numeric(N)
  
  x[1] <- x0
  y[1] <- y0
  
  for (t in 2:N) {
    ## 1. sample X | Y
    x[t] <- rbinom(1, size = n, prob = y[t - 1])
    
    ## 2. sample Y | X
    shape1 <- x[t] + a
    shape2 <- n - x[t] + b
    y[t] <- rbeta(1, shape1 = shape1, shape2 = shape2)
  }
  
  data.frame(iter = 1:N, x = x, y = y)
}

# 对单个参数：theta_mat 为 n_iter x n_chain 矩阵
gelman_rhat_one <- function(theta_mat) {
  n <- nrow(theta_mat)
  m <- ncol(theta_mat)
  
  # 每条链的均值与方差
  chain_means <- colMeans(theta_mat)
  chain_vars  <- apply(theta_mat, 2, var)
  
  # 链间方差 B
  B <- n * var(chain_means)   # var 默认除以 m-1
  
  # 链内方差 W
  W <- mean(chain_vars)
  
  # 后验方差估计
  var_hat <- (n - 1) / n * W + B / n
  
  # Rhat
  Rhat <- sqrt(var_hat / W)
  return(Rhat)
}

# 多参数版本：samples 为 n_iter x n_chain x n_param 的数组
gelman_rhat_all <- function(samples) {
  dims <- dim(samples)
  n_iter  <- dims[1]
  n_chain <- dims[2]
  if (length(dims) == 2) {
    return(gelman_rhat_one(samples))
  }
  n_param <- dims[3]
  
  Rhat_vec <- numeric(n_param)
  for (k in 1:n_param) {
    theta_mat <- samples[ , , k, drop = FALSE]
    theta_mat <- matrix(theta_mat, nrow = n_iter, ncol = n_chain)
    Rhat_vec[k] <- gelman_rhat_one(theta_mat)
  }
  names(Rhat_vec) <- paste0("param", 1:n_param)
  return(Rhat_vec)
}

run_until_converged <- function(init_states,
                                sampler_fun,
                                n_batch = 1000,
                                max_batch = 50,
                                burn_in_prop = 0.5,
                                Rhat_threshold = 1.2,
                                verbose = TRUE,
                                ...) {
  n_chain <- length(init_states)
  
  # 存每条链的样本
  chain_list <- vector("list", length = n_chain)
  current_states <- init_states
  
  total_iter <- 0
  Rhat_vec <- NULL
  
  for (b in 1:max_batch) {
    if (verbose) cat("===== Batch", b, "=====\n")
    
    # 每条链追加 n_batch 步
    for (j in 1:n_chain) {
      res <- sampler_fun(current_states[[j]], n_batch, ...)
      # 更新当前状态
      current_states[[j]] <- res$last
      
      # 追加样本
      if (is.null(chain_list[[j]])) {
        chain_list[[j]] <- res$path
      } else {
        chain_list[[j]] <- rbind(chain_list[[j]], res$path)
      }
    }
    
    total_iter <- total_iter + n_batch
    
    # 至少有两批之后再算 Rhat（防止样本太少）
    if (total_iter >= 2 * n_batch) {
      n_iter <- nrow(chain_list[[1]])
      p <- ncol(chain_list[[1]])
      
      # burn-in
      burn_in <- floor(n_iter * burn_in_prop)
      if (burn_in >= n_iter) burn_in <- floor(n_iter / 2)
      
      kept_idx <- (burn_in + 1):n_iter
      n_kept <- length(kept_idx)
      
      # 组装成 n_kept x n_chain x p 数组
      samples_array <- array(NA, dim = c(n_kept, n_chain, p))
      for (j in 1:n_chain) {
        samples_array[, j, ] <- chain_list[[j]][kept_idx, , drop = FALSE]
      }
      
      # 计算 Rhat
      Rhat_vec <- gelman_rhat_all(samples_array)
      
      if (verbose) {
        cat("  Total iterations per chain:", n_iter, "\n")
        cat("  Rhat:", Rhat_vec, "\n")
      }
      
      # 判断收敛
      if (all(Rhat_vec < Rhat_threshold)) {
        if (verbose) {
          cat(">>> 收敛：所有参数 Rhat <", Rhat_threshold, "\n")
        }
        return(list(chains = chain_list,
                    Rhat   = Rhat_vec,
                    total_iter = n_iter))
      }
    }
  }
  
  if (verbose) {
    cat(">>> 已达到 max_batch 仍未完全满足 Rhat <", Rhat_threshold, "\n")
  }
  return(list(chains = chain_list,
              Rhat   = Rhat_vec,
              total_iter = ifelse(is.null(chain_list[[1]]),
                                  0, nrow(chain_list[[1]]))))
}

rw_laplace_block <- function(state, n_iter, sigma) {
  x <- numeric(n_iter)
  current <- state
  accepted <- 0
  
  for (i in 1:n_iter) {
    proposal <- rnorm(1, mean = current, sd = sigma)
    
    # log 目标密度（未归一化）：log pi(x) = -|x|
    log_pi_current  <- -abs(current)
    log_pi_proposal <- -abs(proposal)
    
    log_alpha <- log_pi_proposal - log_pi_current
    if (log(runif(1)) < log_alpha) {
      current <- proposal
      accepted <- accepted + 1
    }
    x[i] <- current
  }
  
  list(path = matrix(x, ncol = 1),
       last = current,
       accepted = accepted)
}

## 联合密度：
##   f(x, y) ∝ C(n, x) y^{x + a - 1} (1 - y)^{n - x + b - 1}
## 条件分布：
##   x | y ~ Binomial(n, y)
##   y | x ~ Beta(x + a, n - x + b)
##
## 我们写一个 Gibbs 单链块采样函数。

gibbs_bivar_block <- function(state, n_iter, a, b, n) {
  # state: c(x, y)
  x <- numeric(n_iter)
  y <- numeric(n_iter)
  current_x <- state[1]
  current_y <- state[2]
  
  for (i in 1:n_iter) {
    # 先抽 x | y
    current_x <- rbinom(1, size = n, prob = current_y)
    
    # 再抽 y | x
    current_y <- rbeta(1, shape1 = current_x + a,
                          shape2 = n - current_x + b)
    
    x[i] <- current_x
    y[i] <- current_y
  }
  
  path <- cbind(x, y)
  list(path = path,
       last = c(current_x, current_y))
}

Answer

(1)

用给定的分布生出样本\(X_1,X_2,X_3\)(样本量为N)，对任意给定的\(\alpha\)，利用\(p_i(\alpha)=\frac{1}{1+e^{-(a+b1X_1i+b2X_2i+b3X_3i)}}\)计算样本内的平均值\(\bar{p}(\alpha)\approx E[p]\),定义\(g(\alpha)=\bar{p}(\alpha)-f_0\)用 uniroot 在一个合适区间上求方程 \(g(\alpha)=0\)的根，即所求\(\alpha\)

alpha_fun <- function(N, b1, b2, b3, f0, seed = 12345) {
  set.seed(seed)

  ## 1. 生成协变量
  x1 <- rpois(N, lambda = 1)        # X1 ~ Poi(1)
  x2 <- rexp(N, rate = 1)           # X2 ~ Exp(1)
  x3 <- rbinom(N, size = 1, prob = 0.5)  # X3 ~ Bernoulli(0.5)

  ## 2. 定义 g(alpha) = mean(p) - f0
  g <- function(alpha) {
    eta <- alpha + b1 * x1 + b2 * x2 + b3 * x3
    p   <- 1 / (1 + exp(-eta))
    mean(p) - f0
  }

  ## 3. 数值求根，求解 g(alpha) = 0
  sol <- uniroot(g, interval = c(-50, 50))  # 区间可以按需要调

  alpha <- sol$root
  return(alpha)
}

Question

Refer to the Bayesian prediction application in Example 11.3, with the Geometric(p) survival model. Prove that the derived parameter\(\psi(p)=\frac{p}{1-p}\)does not depend on attained age of the individual in this model. (This is not true in general for other models.)

Answer 11.4

设随机变量 \(T\) 为某个体的总寿命（以离散时间度量，\(T=0,1,2,\dots\)）。 在几何生存模型下， \[ \Pr(T = k) = p^{k}(1-p), \qquad k = 0,1,2,\dots \] 其中 \(p\) 为每一时间段存活的概率。例 11.3 已经给出 \[ \mathbb{E}[T] = \frac{p}{1-p}. \]

现在考虑已知该个体已经存活到第 \(a\) 个时间段的情形，即事件 \(\{T \ge a\}\)。 定义在此条件下的剩余寿命为 \[ R_a = T - a \quad \text{(在条件 $T \ge a$ 下)}. \] 我们要证明：\(R_a\) 的期望 \[ \mathbb{E}[R_a] = \frac{p}{1-p} \] 与 \(a\) 无关，从而派生参数 \[ \psi(p) = \frac{p}{1-p} \] 不依赖于个体的已存活年龄 \(a\)。

首先计算 \(R_a\) 的条件分布。对任意 \(r=0,1,2,\dots\)，有 \[ \Pr(R_a = r \mid T \ge a) = \Pr(T = a+r \mid T \ge a) = \frac{\Pr(T = a+r)}{\Pr(T \ge a)}. \] 分子为 \[ \Pr(T = a+r) = p^{a+r}(1-p). \] 分母为 \[ \Pr(T \ge a) = \sum_{k=a}^{\infty} \Pr(T = k) = \sum_{k=a}^{\infty} p^{k}(1-p) = (1-p)\sum_{k=a}^{\infty} p^{k} = (1-p)\,p^{a}\sum_{j=0}^{\infty} p^{j} = (1-p)\,p^{a}\cdot\frac{1}{1-p} = p^{a}. \] 于是 \[ \Pr(R_a = r \mid T \ge a) = \frac{p^{a+r}(1-p)}{p^{a}} = p^{r}(1-p), \qquad r=0,1,2,\dots \] 这正是几何分布 \(\mathrm{Geom}(p)\) 的概率质量函数，且显然不含 \(a\)。 因此，在条件 \(T \ge a\) 下，剩余寿命 \(R_a\) 与原始寿命 \(T\) 具有相同的几何\((p)\) 分布。

由此可得 \[ \mathbb{E}[R_a] = \mathbb{E}[T] = \frac{p}{1-p}, \] 完全与 \(a\) 无关。于是，在几何生存模型下，期望剩余寿命这一派生参数 \[ \psi(p) = \frac{p}{1-p} \] 不依赖于个体的已存活年龄（attained age），证毕。

设\(X_1,\cdots,X_n\stackrel{\text{i.i.d.}}{\sim}Exp(\lambda)\)因为某种原因只知道\(X_i\)落在区间\((\mu_i,v_i)\)其中\(\mu_i \lt v_i\) 非随机 (1)试分别直接极大化观测数据的似然函数与采用EM算法求解\(\lambda\)的MLE.证明EM算法收敛于观测数据的MLE，且收敛有线性速度 (2)设\((\mu_i,v_i),i=1,\dots,n(=10)\)的观测值为(11,12),(8,9),(27,28),(13,14),(16,17),(0,1),(23,24),(10,11),(24,25),(2,3)试分别编程实现上述两种算法并比较结果

Answer

(1)

设 \[ X_1,\dots,X_n\stackrel{\text{i.i.d.}}{\sim}\mathrm{Exp}(\lambda), \qquad f(x\mid\lambda)=\lambda e^{-\lambda x},\ x>0, \] 但第 \(i\) 个样本只知道 \(X_i\in(\mu_i,v_i)\)，其中 \(\mu_i<v_i\) 为非随机常数。 记 \(d_i=v_i-\mu_i>0\)。

对单个观测， \[ P(\mu_i<X_i<v_i\mid\lambda) =F(v_i)-F(\mu_i) =\bigl(1-e^{-\lambda v_i}\bigr)-\bigl(1-e^{-\lambda\mu_i}\bigr) =e^{-\lambda\mu_i}-e^{-\lambda v_i}. \] 因此观测数据的似然函数为 \[ L(\lambda) =\prod_{i=1}^n\bigl(e^{-\lambda\mu_i}-e^{-\lambda v_i}\bigr) =\prod_{i=1}^n e^{-\lambda\mu_i}\bigl(1-e^{-\lambda d_i}\bigr), \] 其对数似然为 \[ \ell(\lambda) =\log L(\lambda) =\sum_{i=1}^n\left[-\lambda\mu_i+\log\bigl(1-e^{-\lambda d_i}\bigr)\right]. \]

对 \(\lambda\) 求一阶导数（得分函数）： \[ \ell'(\lambda) =\sum_{i=1}^n\left[-\mu_i+\frac{d_i e^{-\lambda d_i}}{1-e^{-\lambda d_i}}\right] =\sum_{i=1}^n\left[-\mu_i+\frac{d_i}{e^{\lambda d_i}-1}\right]. \] 令 \(\ell'(\lambda)=0\) 得到极大似然估计 \(\hat\lambda\) 满足 \[ \;\sum_{i=1}^n\mu_i =\sum_{i=1}^n\frac{d_i}{e^{\hat\lambda d_i}-1}\; \tag{$\ast$} \] 。

二阶导数为 \[ \ell''(\lambda) =\sum_{i=1}^n \frac{\mathrm{d}}{\mathrm{d}\lambda} \left(\frac{d_i e^{-\lambda d_i}}{1-e^{-\lambda d_i}}\right) =\sum_{i=1}^n \left(-\frac{d_i^2 e^{-\lambda d_i}}{(1-e^{-\lambda d_i})^2}\right)<0, \] 故 \(\ell(\lambda)\) 关于 \(\lambda\) 为严格凹函数，得分方程 \((\ast)\) 只有一个根， 该根即为观测数据的唯一 MLE。

把真实的 \(X_i\) 视为完整数据，区间 \((\mu_i,v_i)\) 为不完全数据。

为 \[ \ell_c(\lambda) =\sum_{i=1}^n(\log\lambda-\lambda X_i) =n\log\lambda-\lambda\sum_{i=1}^n X_i. \]

在第 \(t\) 次迭代中，参数为 \(\lambda^{(t)}\)。

计算 \[ Q(\lambda\mid\lambda^{(t)}) =\mathbb{E}_{\lambda^{(t)}}\!\bigl[\ell_c(\lambda)\mid \mu_i<X_i<v_i,\ i=1,\dots,n\bigr] =n\log\lambda-\lambda\sum_{i=1}^n \mathbb{E}_{\lambda^{(t)}}\!\bigl[X_i\mid\mu_i<X_i<v_i\bigr]. \]

对固定的 \(i\)，在参数为 \(\lambda\) 时 \[ f_{X_i\mid\mu_i<X_i<v_i}(x\mid\lambda) =\frac{\lambda e^{-\lambda x}} {e^{-\lambda\mu_i}-e^{-\lambda v_i}}, \qquad \mu_i<x<v_i. \] 于是 \[ \mathbb{E}(X_i\mid\mu_i<X_i<v_i,\lambda) =\frac{\displaystyle\int_{\mu_i}^{v_i}x\lambda e^{-\lambda x}\,\mathrm{d}x} {e^{-\lambda\mu_i}-e^{-\lambda v_i}}. \]

利用 \[ \int x e^{-\lambda x}\,\mathrm{d}x =-\Bigl(\frac{x}{\lambda}+\frac{1}{\lambda^2}\Bigr)e^{-\lambda x}, \] 计算可得 \[ \int_{\mu_i}^{v_i}x\lambda e^{-\lambda x}\,\mathrm{d}x =(\mu_i+\tfrac{1}{\lambda})e^{-\lambda\mu_i} -(v_i+\tfrac{1}{\lambda})e^{-\lambda v_i}. \] 令 \(d_i=v_i-\mu_i\)，整理得到 \[ \mathbb{E}(X_i\mid\mu_i<X_i<v_i,\lambda) =\mu_i+\frac{1}{\lambda} -\frac{d_i e^{-\lambda d_i}}{1-e^{-\lambda d_i}} =\mu_i+\frac{1}{\lambda} -\frac{d_i}{e^{\lambda d_i}-1}. \]

因此在 \(\lambda^{(t)}\) 下， \[ E_i^{(t)} :=\mathbb{E}_{\lambda^{(t)}}(X_i\mid\mu_i<X_i<v_i) =\mu_i+\frac{1}{\lambda^{(t)}} -\frac{d_i}{e^{\lambda^{(t)} d_i}-1}. \]

\[ Q(\lambda\mid\lambda^{(t)}) =n\log\lambda-\lambda\sum_{i=1}^n E_i^{(t)}. \] 对 \(\lambda\) 求导并令为零： \[ \frac{\partial Q}{\partial\lambda} = \frac{n}{\lambda}-\sum_{i=1}^n E_i^{(t)}=0 \quad\Longrightarrow\quad \lambda^{(t+1)} =\frac{n}{\sum_{i=1}^n E_i^{(t)}}. \]

将 \(E_i^{(t)}\) 的表达式代入，得到 EM 迭代公式 \[ \lambda^{(t+1)}= \left[ \frac{1}{n}\sum_{i=1}^n \left( \mu_i+\frac{1}{\lambda^{(t)}} -\frac{d_i}{e^{\lambda^{(t)} d_i}-1} \right) \right]^{-1}. \]

记 \[ S(\lambda) =\sum_{i=1}^n \mathbb{E}(X_i\mid\mu_i<X_i<v_i,\lambda), \qquad M(\lambda)=\frac{n}{S(\lambda)}. \] 则 EM 迭代可写为 \[ \lambda^{(t+1)}=M(\lambda^{(t)}). \]

若迭代收敛到极限 \(\lambda^\ast\)，则必为映射 \(M\) 的不动点： \[ \lambda^\ast = M(\lambda^\ast) \ \Longleftrightarrow\ S(\lambda^\ast)=\frac{n}{\lambda^\ast}. \] 由 \[ S(\lambda) =\sum_{i=1}^n\mu_i+\frac{n}{\lambda} -\sum_{i=1}^n\frac{d_i}{e^{\lambda d_i}-1}, \] 代入 \(S(\lambda^\ast)=n/\lambda^\ast\) 得 \[ \sum_{i=1}^n\mu_i =\sum_{i=1}^n\frac{d_i}{e^{\lambda^\ast d_i}-1}, \] 这恰好是得分方程 \((\ast)\)，因此任何 EM 不动点必为观测数据的 MLE。 由于 \(\ell(\lambda)\) 严格凹、MLE 唯一，EM 一旦收敛，就必然收敛到该 MLE。

进一步，关于 EM 的一般理论给出在 MLE \(\hat\lambda\) 附近 \[ M'(\hat\lambda) =1-\frac{I_{\mathrm{obs}}(\hat\lambda)}{I_{\mathrm{comp}}(\hat\lambda)}, \] 其中 \(I_{\mathrm{comp}}(\lambda)=n/\lambda^2\) 是完整数据的 Fisher 信息， \(I_{\mathrm{obs}}(\lambda)=-\ell''(\lambda)\) 是观测（区间）数据的 Fisher 信息。 由信息分解 \[ I_{\mathrm{comp}}(\lambda) =I_{\mathrm{obs}}(\lambda)+I_{\mathrm{mis}}(\lambda), \qquad I_{\mathrm{mis}}(\lambda)>0, \] 可得 \[ 0<M'(\hat\lambda) =\frac{I_{\mathrm{mis}}(\hat\lambda)}{I_{\mathrm{comp}}(\hat\lambda)}<1. \] 因此在 \(\hat\lambda\) 邻域内， \[ \lambda^{(t+1)}-\hat\lambda \approx M'(\hat\lambda)\bigl(\lambda^{(t)}-\hat\lambda\bigr), \] 从而 EM 算法以线性速度收敛于观测数据的 MLE。

EM_exp_interval <- function(lambda0,
                            mu, v,
                            tol = 1e-8,
                            maxit = 1000,
                            trace = TRUE) {
  d <- v - mu
  n <- length(mu)
  lambda <- lambda0
  history <- data.frame(iter = 0,
                        lambda = lambda,
                        loglik = loglik(lambda))

  for (k in 1:maxit) {
    ## E-step: 计算条件期望 E[X_i | mu_i < X_i < v_i, lambda]
    ## 使用简化公式：E = mu + 1/lambda - d/(exp(lambda*d) - 1)
    eX <- mu + 1 / lambda - d / (exp(lambda * d) - 1)
    S  <- sum(eX)

    ## M-step: 更新 lambda
    lambda_new <- n / S

    history <- rbind(history,
                     data.frame(iter = k,
                                lambda = lambda_new,
                                loglik = loglik(lambda_new)))

    if (abs(lambda_new - lambda) < tol) {
      if (trace) print(history)
      return(list(lambda = lambda_new,
                  iter   = k,
                  history = history))
    }
    lambda <- lambda_new
  }
  if (trace) print(history)
  list(lambda = lambda,
       iter   = maxit,
       history = history)
}

# 定义快速卡方检验函数
fast_chisq_test <- function(x, y) {
  # 1. 既然输入是两个向量，首先需要将其转换为列联表（Observed counts）
  #    注意：如果向量包含大量的唯一整数，table() 可能是性能瓶颈，
  #    但对于一般分类数据，这是必须的步骤。
  observed <- table(x, y)
  
  # 2. 检查是否有全零的行或列（可选，但在数学计算中为了避免除以0是必要的，
  #    不过题目假设无缺失值且隐含数据有效，为了极致速度可以略过，这里保留基本逻辑）
  #    但在极简版本中，我们假设数据是良好的。
  
  # 3. 计算期望值 (Expected counts)
  #    公式：E = (RowSums * ColSums) / Total
  nr <- nrow(observed)
  nc <- ncol(observed)
  sr <- rowSums(observed)
  sc <- colSums(observed)
  n  <- sum(observed)
  
  # 使用 outer 函数计算外积矩阵，比循环快
  expected <- outer(sr, sc, "*") / n
  
  # 4. 计算卡方统计量
  #    公式：sum((O - E)^2 / E)
  #    注意：这里我们不进行 Yates 连续性修正，直接计算皮尔逊卡方
  statistic <- sum((observed - expected)^2 / expected)
  
  return(statistic)
}

Can you make a faster version of table() for the case of an input of two integer vectors with no missing values? Can you use it to speed up your chi-square test?

set.seed(1)
fast_table <- function(x, y) {
  # 1. 获取唯一值并排序，确定矩阵维度
  #    注意：虽然 match 和 unique 有开销，但比 factor() 转换要快。
  #    如果已知输入就是 1:N 的整数，甚至可以跳过这一步直接用 max(x)。
  x_unique <- sort(unique(x))
  y_unique <- sort(unique(y))
  
  nx <- length(x_unique)
  ny <- length(y_unique)
  
  # 2. 将 x 和 y 映射为 1 到 N 的整数索引
  #    这是为了防止输入是很稀疏的整数（如 c(1, 10000)），导致分配过大的内存
  xi <- match(x, x_unique)
  yi <- match(y, y_unique)
  
  # 3. 计算一维扁平索引 (Flattened Index)
  #    这就好比把矩阵一列一列地接起来变成一条长向量
  #    公式：(列号 - 1) * 总行数 + 行号
  index <- (yi - 1) * nx + xi
  
  # 4. 使用 tabulate 进行底层快速计数
  counts <- tabulate(index, nbins = nx * ny)
  
  # 5. 将结果重塑为矩阵
  matrix(counts, nrow = nx, ncol = ny)
}
super_fast_chisq <- function(x, y) {
  # --- 优化点：使用我们自定义的 fast_table ---
  observed <- fast_table(x, y)
  
  # 下面的逻辑与上一题保持一致
  nr <- nrow(observed)
  nc <- ncol(observed)
  sr <- rowSums(observed)
  sc <- colSums(observed)
  n  <- sum(observed)
  
  expected <- outer(sr, sc, "*") / n
  
  # 避免除以0的潜在警告（虽然题目假设无缺失且有效，这里稍微稳健一点）
  # 在极速版中通常不加这个检查，或者假设 expected > 0
  sum((observed - expected)^2 / expected)
}

gibbs_sampler_r <- function(n_iter, y, start_theta) {
  y1 <- y[1]; y2 <- y[2]; y3 <- y[3]; y4 <- y[4]
  theta_chain <- numeric(n_iter)
  theta <- start_theta
  a <- 1.0; b <- 1.0
  
  for(i in 1:n_iter) {
    # Step 1: Data Augmentation (Update x2)
    # 计算二项分布的概率 prob
    prob_x2 <- theta / (2.0 + theta)
    # 生成 x2
    x2 <- rbinom(1, size = y1, prob = prob_x2)
    
    # Step 2: Parameter Update (Update theta)
    # 计算 Beta 分布的参数
    shape1 <- x2 + y4 + a
    shape2 <- y2 + y3 + b
    # 生成 theta
    theta <- rbeta(1, shape1, shape2)
    
    theta_chain[i] <- theta
  }
  return(theta_chain)
}
